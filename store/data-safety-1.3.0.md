# Tablamigo 1.3.0: Google Play Data safety answers

What this is: the answers to type into Play Console, App content, Data safety, for the 1.3.0 build (versionCode 8): no ads, no voice notes, no government ID, trusted contacts, precise location only while the app is open, a rounded location on moments, first-party analytics, payments through Google Play Billing. Each row names the code that collects the data. Nothing has been entered in Play Console; that is yours to do.

Basis: `origin/main` at `531fa48` (4 Oct 2026), plus the unmerged `feat/app-1.3.0` branch for the features that are removed (no ad banner `34caafb`, Razorpay checkout kept out of the native bundle `c53f5b2`). Paths are from the repo root. Google's definitions used: **collect** is data sent off the device (including by an SDK); **share** is a transfer to a third party, not counting a service provider that processes it for us, a transfer for legal reasons, or one the user starts and expects. A person who posts something for other users to see is not a third party. Five calls are yours to make, in section 4.

## 4. Calls for you to make

- **D1, OpenStreetMap services and location.** Default: mark Approximate location, Precise location and In-app search history as shared, for App functionality. The phone sends the typed place and, for a plan, the exact position to Photon (`apps/mobile/src/app/activity/new.tsx:55`), loads map tiles from OpenFreeMap, and our server sends exact coordinates to Nominatim (`apps/api/src/lib/geo.ts:33`; the rounding in `apps/api/src/lib/geo.ts:4` only builds the cache key). They are public services without a contract with us, so the service-provider exemption is thin. Marking them shared puts "may share location" on the listing. The alternative is "not shared", which is only safe if Photon is not given the position and Nominatim gets rounded points: a small API and app change that I did not make.
- **D2, OpenAI.** Default: not shared, because it only returns a verdict or an idea for us. I did not check OpenAI's own API data terms. If you want to be strict, mark Other in-app messages and Other info as shared for Fraud prevention, security, and compliance and App functionality.
- **D3, Contacts.** Default: declare it, because Play describes the type as contact names and the app stores them. The narrower choice is Name and Phone number only.
- **D4, IP address.** Default: declare it under Device or other IDs for security. Play's form has no IP address option.
- **D5, other users.** Default: other users are not third parties, so profile, plan, moment and tip data is not "shared". Moments, comments and city tips are readable by anyone, signed in or not (`apps/api/src/routes/moments.ts:19-75`, `apps/api/src/routes/cities.ts:207-238`).
