# Privacy claims: where each statement comes from

What this is: for every factual statement in `src/privacy.html` and `src/delete-account.html`, and for the SOS, verified-badge, billing and partnerships wording on the other pages, the file and line in the code that makes it true. An earlier version of these pages failed review because they said more (or less) than the code does, so each line below was read in the code, not inferred.

How it was checked: read against `origin/main` at `531fa48` on 4 Oct 2026 (branch `fix/web-should-fix-1004`). Paths are from the repo root and line numbers are at that commit. Nothing was run against production, and I had no access to the server, so anything that depends on how the service is run is marked OPS.

Status key:

- **CODE**: read in the code at the commit above.
- **OPS**: depends on infrastructure or production settings that are not in the repo (hosting region, public media address, cache headers, log rotation, which environment variables are set). Only the owner can confirm it.
- **COMMITMENT**: a promise or a choice, not behaviour of code (for example "we reply within 30 days").
- **PENDING**: a branch that is not merged yet changes it (section 6). Re-read it when that branch lands.
